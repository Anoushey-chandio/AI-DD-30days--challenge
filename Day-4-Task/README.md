 ### PDF Summarizer & Quiz Generator Agent

**Role:** Senior Python AI Engineer  
**Objective:** Build a minimal web-based study assistant that summarizes PDFs and generates quizzes using Streamlit and the `openai-agents` SDK.

---

## Features

- Summarize PDF documents
- Generate quizzes (MCQs or mixed style)
- Uses PyPDF extraction tools
- Minimal, zero-bloat Streamlit UI

---

## Tech Stack

- **UI:** Streamlit
- **Model:** Google Gemini (`gemini-2.0-flash-001`) via `openai-agents` SDK
- **Tools:** PyPDF for PDF text extraction
- **Dependency Management:** `uv`
