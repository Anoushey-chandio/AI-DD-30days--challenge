### Short Note on Spec-Kit Plus
Spec-Kit Plus is a toolkit used for spec-driven software development, where the creation of clear specifications becomes the foundation of the entire development process. Instead of starting directly with coding, developers first write detailed specifications that describe the system’s requirements, behavior, and goals. Spec-Kit Plus then helps transform these specifications into structured project plans, architecture outlines, and task lists.
This method improves clarity, reduces misunderstandings, and ensures that the final software stays aligned with the original requirements. It is especially useful for AI-assisted development and team-based projects because it promotes consistency and better organization.

### Constitution
The Constitution Phase sets fixed project-wide rules and quality standards for all work. It acts as a rulebook guiding every specification, plan, task, and implementation, ensuring consistency and high-quality results.

### Specify
The Specify Phase defines clear, testable requirements for a project or feature. It states what to achieve, success criteria, constraints, and non-goals, ensuring all planning and implementation follow the intended objectives.

### Plan
The Plan Phase turns the specification into a clear strategy. It defines the project’s structure, phases, dependencies, and key decisions (ADRs) to ensure all work is organized and follows the specification.
Example: Research → Writing → Analysis → Synthesis, with documented decisions on workflow.

### Tasks
In the Tasks Phase, the plan is broken into small work units (15–30 min) called tasks. Each task has one clear goal, produces a verifiable output, follows dependencies, and is reviewed at checkpoints.
Example:
•	“Find 5 credible sources for Section 1” → bibliography
•	“Summarize key points from Section 1” → research notes
Key: Small, testable, and reviewable steps ensure progress and quality.

### Implement
The Implement Phase is where you execute tasks with AI, following your plan and specification. Work is done in small units, reviewed at checkpoints to ensure it meets success criteria. If a task doesn’t meet spec, you iterate with AI until it does. This ensures quality, controlled execution, and collaboration.
